# anzeigen
anzeigen ist eine Online-Plattform, auf der Nutzer Gegenstände anbieten und suchen können. Anbieter und Interessenten treten über ein Nachrichtensystem miteinander in Kontakt und vereinbaren alle Einzelheiten untereinander. Die Bezahlung und Übergabe der Waren organisieren die Nutzer selbstständig.

## Funktionsübersicht
- Benutzerregistrierung, Anmeldung und Abmeldung
- Suchfunktion
- Sortierfunktion
- Detailansicht einer Anzeige
- Aktive Anzeigen anderer Nutzer, eigene Anzeigen, oder Anzeigen in der Merkliste anzeigen
- Anzeigen reservieren/aktivieren
- Anzeigen/Entwürfe erstellen, bearbeiten und löschen
- Anzeigen zur Merkliste hinzufügen oder aus der Merkliste entfernen.
- Nachrichtensystem
  - Einen neuen Chat starten
  - Chats löschen
  - Sortierfunktion für Chats
  - Nachrichten schreiben und senden
- Benutzerdaten ändern

## Installation
1.	Docker Desktop installieren.
2.	Das Projekt herunterladen und entpacken
3.	Eingabeaufforderung (Command Prompt / CMD) öffnen. 
    1.	Zum Verzeichnis "project-anzeigen" navigieren.
    2.	"docker compose build" ausführen. (und warten, bis der Vorgang vollständig abgeschlossen ist)
    3.	"docker compose up -d" ausführen. (und warten, bis der Container vollständig gestartet ist. Es dauert etwa 30 Sekunden)
4.	Anwendung in einem Browser öffnen: http://localhost:8080/
